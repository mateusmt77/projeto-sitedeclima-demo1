# projeto-sitedeclima-demo1
Projeto voltado para treinamento de tecnologias como: Html, Css, JS, Node.js e Frameworks. Este projeto tem como objetivo construir um site funcional aonde o usuário poderá pesquisar o clima de sua cidade a partir de uma API externa 

*Pré-Requisitos* 
- O Site deverá fornecer o clima para o usuário baseado em uma consulta feita diretamente pela barra de endereço de buscas principal
- O Site deverá retornar o clima atualizado daquela região específica para o usuário usando a medição de temperatura padrão: **°C**
- Nosso site conterá além da barra de pesquisa de clima para o usuário, uma imagem que representará o clima naquela região específica podendo variar entre: *Quente, Nublado, Chuva ou Tempestade*. Inicialmente usaremos essas 4 medições mais comuns de clima. Posteriormente faremos atualizações
- O Site será hospedado posteriormente na *Vercel* e usuará a API de clima *OpenWeather* para consultar a temperatura de uma região

*Restrições* 
- O Site deverá retornar erro caso uma cidade não conhecida seja enviada para consulta
- O Site não permitirá o uso de CEP ou localização em tempo real (inicialmente)
- O usuário precisará ter facilidade no uso, sem eventuais problemas de processamento ou demora no carregamento das informações
- O Site não pedirá como requisito para que uma consulta seja feita, o login ou senha do usuário, bastando apenas que o mesmo digite sua busca na barra de pesquisa

*Prazos de Implementação e Checklist* 

1. Passo 1 - Definir a arquitetura do projeto / Prazo: 1-2 dias 
2. Passo 2 - Definir tecnologias que serão utilizadas / Prazo: 1-2 dias 
3. Passo 3 - Aplicar Versionamento Git / Prazo: 1 dia
